# Proposta de landing page — Dra. Thaynny de Paula Estética Avançada

Proposta de layout para a clínica Dra. Thaynny de Paula Estética Avançada (Aparecida de Goiânia - GO).
**Não é o site oficial da clínica.**

- Página estática: `index.html` (Tailwind via CDN) + imagens em `assets/`
- Textos, depoimentos e contatos vêm do site oficial e da ficha pública da clínica no Google
- A página tem `noindex, nofollow` para não aparecer nas buscas
